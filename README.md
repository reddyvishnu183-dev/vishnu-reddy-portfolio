# Vishnu Reddy Singireddy — Spider-Verse Portfolio with Research

Responsive portfolio with the research paper section, Spider-Man-inspired red/blue styling, and an animated original masked web-slinger silhouette.

## Preview
1. Extract the ZIP.
2. Keep `index.html`, `styles.css`, `script.js`, and `background.jpg` (if included) together.
3. Open `index.html` in a browser.

The character motion is CSS/SVG based and does not require external animation assets. It respects the browser's reduced-motion preference.


## Interactive action-figure display
Open `index.html` in a browser. Scroll to **The Web-Slinger Display** to use the rotation slider, drag controls, left/right rotation, vertical tilt, and auto-spin. The uploaded images act as visual frames at approximate angles; this is a 2.5D interactive display rather than a true 3D model.
